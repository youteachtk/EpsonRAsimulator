## Verified robot characteristics

Official Epson documentation identifies the C4-A601S as a compact six-axis articulated robot.

- Degrees of freedom: 6
- Reach: 600 mm
- Maximum payload: 4 kg
- Mounting: tabletop or ceiling configuration
- Controller family: RC700-A
- Robot software family: EPSON RC+ 7.0

## 3D geometry source

Epson publishes an official 3D STEP package for the C4-A601S. This is the preferred geometry source for creating the optimized GLB/glTF model used by the Android simulator.

Official STEP package path published by Epson:
https://eposs.epson.com.cn/EPSON/assets/resource/Download/Robot/C4-A601S/C4-A601S-step.zip

The STEP model must be converted/optimized for real-time rendering and separated into articulated links before use in the app.

## Implementation tasks

1. Obtain official STEP geometry.
2. Inspect assembly/link hierarchy.
3. Separate meshes by moving link/joint.
4. Establish J1-J6 pivot origins and axes.
5. Export optimized GLB/glTF.
6. Map visual nodes to RobotDefinition.
7. Implement forward kinematics against Epson dimensions.
8. Validate known poses against RC+ simulator.
9. Add inverse kinematics and touch TCP control.
