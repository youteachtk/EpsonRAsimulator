# Robot and Tool Assets

Place GLB/glTF assets here.

Planned structure:

- robots/<model-id>/robot.glb
- tools/two-finger-gripper.glb
- tools/vacuum.glb
- tools/welding-torch.glb
- tools/hand.glb
- workcell/

Robot assets must use a documented node naming/mapping scheme so links can be animated from joint state.

Do not add an arbitrary Epson model until the exact robot used by the learner is identified.
